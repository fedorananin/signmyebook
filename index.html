How it works

  1. Choose an EPUB or FB2 file. Your browser reads it; nothing is sent to a server.
  2. Write a dedication. If you like, draw a signature with a mouse, finger or stylus, or upload a photo of one you signed on paper. A place and date are optional too.
  3. Download the signed copy. The new page goes right after the cover, and the rest of the book stays exactly as it was. Your original file isn't touched.

What people use it for

  • Gifts from authors. A copy for a friend, a relative, or the colleague who kept asking how the book was going.
  • A bonus for supporters. Signed copies with the reader's name for patrons on Patreon, Substack, Gumroad or Ko-fi.
  • After an online event. At an in-person reading you'd sign books at a table afterwards. After a Zoom talk, a podcast or a book-club call, you can send each reader a signed file instead.
  • Gifts from readers. You don't have to be the author. Giving an ebook to a friend or a child? Write them a note in the front, like you would in a hardcover.

Why I made this

A while ago I met an author. We talked for a while, and before we said goodbye he signed a copy of his book for me: a short dedication, my name, his signature. I still take that paperback off the shelf now and then, and it still feels like someone was there.

Ebooks have nowhere to put that. Every copy is the same file, byte for byte. So I made a small tool that adds one page after the cover, where a dedication and a signature can live.

It's free, and I plan to keep it that way. It runs in your browser because a personal note to someone shouldn't have to pass through my server, or anyone else's.

The code is open source, so you don't have to take my word for any of this. It's on GitHub, and pull requests are welcome.

Questions

Is my book uploaded anywhere?

No. The site is a set of static files. Your browser opens the book, adds the page and saves the new copy, all on your device. The site counts visits with Umami, a cookie-free analytics tool. It records events like "a book was signed" along with the file format, never the file or what you wrote. The source code is public if you'd like to check.

Will the signed file open in Kindle, Apple Books and other readers?

Yes. The result is a regular EPUB or FB2 with one extra page near the front. Apple Books, Calibre, KOReader, Moon+ Reader, FBReader and most other readers open it as usual. For Kindle, send the EPUB with Send to Kindle, or convert it to AZW3 in Calibre.

Does it work with DRM-protected books?

No. It can only edit EPUB and FB2 files without copy protection. Most books bought from Kindle, Kobo or Barnes & Noble have DRM and won't open here, and that's intentional.

Can I sign a book that was already signed?

Yes. If the book already has a SignMyEbook page, the new signature replaces it. Your original file is never changed; every download is a new copy.

Does it cost anything?

No. There is no paid plan, no account and no watermark. Sign as many books as you like.

Can I use it offline?

Yes. Install it from your browser ("Add to Home Screen" or the install icon in the address bar) and it will work without an internet connection.

Is there a file size limit?

No fixed limit. Everything happens in your browser, so the only limit is your device's memory. Very large books can be slow on older phones.

Which languages can I write in?

Any language your keyboard supports, including Russian, Chinese, Arabic and Hebrew, and mixed scripts. The text is stored exactly as you typed it.
